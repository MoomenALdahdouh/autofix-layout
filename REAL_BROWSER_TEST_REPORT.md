## 21. Fixed bugs (this pass)

### P1 — `` `ذلك` `` skipped as shell

**Reproduce:** intended `ذلك` on US QWERTY is `` `g; ``. `skipReasonForToken` treated a leading backtick as shell (`^``), so the planner never remapped it (`هذا بعد \`g;`).

**Fix:** only paired tick commands (`` `code` ``) count as shell. Regression: `skipReasonForToken('\`g;')` is null; `corrected('\`g;') === 'ذلك'`.

### P1 — `حالك?` not repaired

**Reproduce:** `phg;?` (حالك + `?`). Tokenizer peeled `;?` together, leaving `phg`, and the Arabic-letter-punct fallback refused `?`.

**Fix:** `splitTrueTrail` retries the core `phg;` and leaves `?`. `hsjo]lj;` still becomes `استخدمت;` (trailing semicolon is punctuation, not kaf). Regression in accuracy / campaign tests.

## 22. Known limitations (verified in code)

- Paste and drop are ignored (ARCHITECTURE).
- Automatic Turkish/Hebrew/etc. never commits (`shouldCommitMismatch` default `false`).
- Isolated short tokens stay.
- No IME languages.
- Docs/Notion adapters are planned, not implemented.
- Chrome 151 CLI did not load the unpacked extension here.
