# Store assets

Shared Layfix identity for Chrome Web Store and Microsoft Edge Add-ons.

| File | Use |
| --- | --- |
| `icon-300.png` | Store listing logo (300×300). Same mark as the extension. |
| `layfix-chrome.zip` | Created by `npm run pack:chrome` (gitignored) |
| `layfix-edge.zip` | Created by `npm run pack:edge` (gitignored) |

Extension toolbar icons remain `icons/icon-16.png` … `icon-128.png`.

Screenshots are captured by hand on the target browser. Do not invent store URLs.
