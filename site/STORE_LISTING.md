# Store listing copy

Chrome Web Store and Microsoft Edge Add-ons. Same product name: **Layfix**. Do not claim translation, spelling, or IME support. Store listing URLs stay placeholders until they exist: `[CHROME_STORE_URL]`, `[EDGE_ADDONS_URL]`.

## Short description

Forgot to switch your keyboard? Layfix restores the text you meant to type.

## Long description

Layfix restores text typed under the wrong keyboard layout.

You start a word in Arabic, Turkish, or another language — then notice the keyboard was still set to English. Layfix remaps those physical keys so the word you intended appears. Real words, names, and code stay as typed. It does not translate and it does not correct spelling.

**Automatic correction** — After Space, Enter, or Tab, Layfix can fix a finished word in supported text fields.

**Manual converter** — Type or paste in the popup. Conversion is instant and stays on your device.

**Languages** — Enable the keyboards you actually use. Mixed-language sentences stay mixed.

**Free to try** — 7 days of full access, then a daily free allowance for automatic correction. The manual converter remains available. Pro is unlimited automatic correction for $29 / year.

No account is required to install and try Layfix.

## Permissions

- **storage** — Remember your keyboards, toggles, and local cache.
- **activeTab** — Let you skip the site you are looking at.
- **clipboardWrite** — Copy converted text when you click the result.
- **Access to text fields** — Read supported inputs so a finished word can be checked. Password and many secret-like fields are skipped.
- **API host** — Only the configured Layfix API (localhost in development).

Layfix needs access to supported text fields so it can detect keyboard-layout mistakes while you type.

## Privacy (store form)

Manual conversion stays on the device. Automatic correction may send a single word, a little nearby text, a license key, and keyboard IDs so a classifier can decide if the layout is wrong. The page, URL, and history are not sent.

Do not claim that all processing is local. Automatic classification can leave the device.
